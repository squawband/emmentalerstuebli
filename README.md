# Emmentaler Stübli – GitHub Pages

Eine statische, mobilfreundliche Infoseite für das Gästezimmer in Heimiswil. Sie verwendet nur HTML, CSS und die lokalen Fotos im Ordner `assets/`.

## Auf GitHub Pages veröffentlichen

1. ZIP-Datei entpacken.
2. `index.html`, `README.md` und den Ordner `assets/` in das Stammverzeichnis eines GitHub-Repositories hochladen.
3. Im Repository **Settings → Pages** öffnen.
4. Unter **Build and deployment** als Quelle **Deploy from a branch** wählen, dann den gewünschten Branch (zum Beispiel `main`) und `/ (root` auswählen und speichern.
5. Nach dem GitHub-Deployment die angezeigte Pages-Adresse öffnen.

Die Airbnb-Schaltflächen führen zum Inserat `https://www.airbnb.ch/rooms/1801953458288203363`. Die Fotos sind im Unterordner `assets` abgelegt und werden relativ eingebunden.
